# STF (Simple Text Format) for Visual Studio Code

Syntax highlighting for [STF](../../packages/llm-msg-io/docs/stf/README.md) files (`.stf`).

STF is a human-editable, line-oriented plain-text format for storing LLM messages, designed for chat UIs, prompt libraries, and browseable chat archives.

## Features

- Syntax highlighting for STF commands, comments, arguments, and data lines
- Block comment folding support

## Example

```text
;system
You are a helpful assistant.

;user name="Alice"
What is the capital of France?

;ai
The capital of France is Paris.

;# This is a comment
```
